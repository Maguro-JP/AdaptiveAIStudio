# 拡張機能

拡張機能は、本体に同梱した機能のうち、設定で入れたり切ったりできるものです。
いま在るのは「アイデア」（[使い方と仕組み](IDEAS.md)）の 1 つです。

## 使い方

⚙（設定）→ 拡張機能 に、同梱の拡張機能が並びます。チェックを押すと、その場で保存して結果を言います。

- 切る: そのパネルを閉じ、⊞（表示）の一覧からも外します。その拡張機能の API は 404 を返します。データは消えません
- 入れる: そのパネルを出します。切る前のデータが、そのまま戻ります
- データを消す: 拡張機能を切ってから `npm run clean`（配った形では、入口の片づけ）。切ってある拡張機能のデータだけを一覧に出し、`--yes` を付けたときだけ消します。
  入っている拡張機能のデータは、使っているものなので一覧に出しません

設定のファイルでは、`extensions.<id>.enabled` です。書いていなければ、その拡張機能の既定（アイデアは入り）になります。

```json
{ "extensions": { "ideas": { "enabled": false } } }
```

`npm run doctor` に、拡張機能ごとに 1 行出ます（入っているか・同梱のデータの数・残したものの数）。

## 決まり

- 拡張機能は、`src/extensions/registry.ts` の固定の一覧に在るものだけです。外からコードや CSS を読み込む経路は作りません
  （見た目の設定が画面を書き換える経路になるのと同じ理由です。見た目は `tokens` と `effects` に従います）
- 1 つの拡張機能が持つのは、id・名前・説明・パネルの種類・API の接頭辞・データのフォルダ・既定の入り切り、の 7 つです
- パネルの種類は、`src/ui/layout.ts` の `PANEL_KINDS` と `src/ui/web/panels.js` の `PANELS`・`TITLES` に足します。
  切ってある間は、本体が `/api/layout` の `off` で知らせ、画面は一覧に出さず、並びに在れば閉じます
- API は、接頭辞（`/api/<id>`）の下にだけ置きます。切ってある間は、本体の入口で 404 を返します（拡張機能のコードまで届きません）。
  スマホの口（LAN）には出しません
- データは、AAS_HOME のデータの下の `extensions/<フォルダ>/` に置きます。件数に上限を付けます。切っても消しません
- 実行時の依存を足しません。ビルドの段も足しません。ネットワークを呼びません（呼ぶ拡張機能を足すときは、検問を通す形を先に決めます）

## 足すとき

1. `src/extensions/<id>/` に本体を書く（データを同梱するなら、ライセンスの表示を同じフォルダに置く）
2. `src/extensions/registry.ts` の `EXTENSIONS` に 1 行足す
3. パネルを `PANEL_KINDS`・`PANELS`・`TITLES` に足す（`test/panel-kinds.test.ts` が食い違いを止めます）
4. `src/ui/server.ts` の拡張機能の分かれ目に、その拡張機能の API を繋ぐ
5. `npm run doctor` の行と、試験と、画面を押す確かめ（`scripts/check-<id>.mjs` と `checks/<id>.ids`）を足す

## 確かめ

- `test/extensions.test.ts`: 一覧・入り切り・切ると 404・入れ直すとデータが戻る・片づけ・外から読み込む経路が無い
- `scripts/check-ideas.mjs` の `ideas-extension-off-and-on`: 画面で切って、入れ直す
