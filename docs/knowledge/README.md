# 知識の置き場

long-dev が周ごとに書く。新しく分かったことを、将来読み返せる形でその日のうちに。

| ファイル | 中身 |
|---|---|
| `tech.md` | 採用技術、ライブラリ、API、環境固有の問題、設計上の知識 |
| `problems.md` | 起きたバグ、原因、解決、再発防止、採用しなかった案 |
| `ai.md` | 精度の問題、効いた改善・効かなかった改善、評価方法 |
| `decisions.md` | `docs/DECISIONS.md` を指すだけ（決定はそちらに書く決まり） |

ほかに読む所:

| 知りたいこと | 読む所 |
|---|---|
| いま何が在って、何が無いか・未解決のもの | `docs/HANDOFF.md` |
| 作りの地図 | `docs/ARCHITECTURE.md`、`docs/UI.md` |
| モデル・実行の知見 | `docs/LOCAL-MODEL.md`、`docs/GGUF.md`、`docs/RUNNING-LARGE-MODELS.md`、`docs/MODEL-EFFICIENCY.md` |
| まだ無いもの・完成の定義 | `docs/ROADMAP.md`、`docs/RETHINK.md` |
| 不具合の直し方 | `docs/TROUBLESHOOTING.md` |

日報・週報・月報は `docs/reports/`（dev-report が書く）。
