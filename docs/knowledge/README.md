# 知識の置き場

long-dev の原則は、分かったことを `docs/knowledge/` に置くよう求めている。
この場所では、同じ役目の文書が既に在るので、**ここには索引だけを置く。**
中身を写すと二か所に割れて、片方だけが古くなる。

| 知りたいこと | 読む所 |
|---|---|
| いま何が在って、何が無いか・未解決のもの | `docs/HANDOFF.md` |
| なぜこの設計か・別案を採らなかった理由 | `docs/DECISIONS.md`（日付順。末尾から遡る） |
| 起きた不具合と直し方 | `docs/TROUBLESHOOTING.md`、`docs/DECISIONS.md` |
| 作りの地図 | `docs/ARCHITECTURE.md`、`docs/UI.md` |
| モデル・実行の知見 | `docs/LOCAL-MODEL.md`、`docs/GGUF.md`、`docs/RUNNING-LARGE-MODELS.md`、`docs/MODEL-EFFICIENCY.md` |
| まだ無いもの・完成の定義 | `docs/ROADMAP.md`、`docs/RETHINK.md` |

日々・週ごとの報告は `docs/reports/` に置く。
