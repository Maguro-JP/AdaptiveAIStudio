## 2026-09-01  バッチは CP932 で置く（BOM は付けない）

社用PCの実行結果で分かった。cmd.exe はバッチを console の文字集合で読むので、
UTF-8 で置くと行が壊れて断片が実行される。BOM は 1 行目を壊し、`@echo off`
まで効かなくする。`chcp 65001` では直らない（読むのは実行前だから）。

記録は UTF-8 のままにする。`.gitattributes` の `working-tree-encoding=CP932`
で、取り出すときだけ変える。GitHub の「Download ZIP」にも効く（確認済み）。

## 2026-09-01  .exe は名前で落とされる。名前を変えれば置ける

**本番の道（.exe）には触っていない。**後ろに足しただけ。

## 2026-09-01  file:// を文字列で継ぎ足さない

`scripts/run.mjs` と `scripts/bundle.mjs` の入口が
`import.meta.url === \`file://${process.argv[1]}\`` だった。

Windows では `argv[1]` が `Z:\...\run.mjs`（円記号・ドライブ文字）、
`import.meta.url` は `file:///Z:/.../run.mjs`。**一致しないので中身が
丸ごと動かない。**何も言わず終了コード0で終わるため、失敗にも見えない。
実機では「1 を選んでも画面が開かない」という形で出た。

Linux では一致するので、こちらでは永久に気づけない。
**走らせる場所で結果が変わる、の実例。**

`pathToFileURL(process.argv[1]).href` を使う。
`test/home.test.ts` で、文字列の継ぎ足しが無いことと、入口が実際に
動くこと（そんな仕事はない → 終了コード2）の両方を見る。

## 2026-09-01  二つ目の実行ファイルを起こさない（NetVision に倣う）

利用者に「NetVision だと動くのに、なぜこっちは動かないのか」と問われて、
**初めて NetVision を見た。**見ずに WASM を提案していた。

NetVision の `backend/app/services/llm_inproc.py` に、答えがそのまま書いてある。

> サーバーを別に立てる形（Ollama や llama.cpp の server）は、
> 実行ファイルが1つ増えるため、そこで止まる。

| | NetVision | AdaptiveAIStudio（これまで） |
|---|---|---|
| 土台 | `python.exe`（アプリ自身） | `node.exe`（`.bin` でも可） |
| モデルを読むもの | `lib/` の `llama-cpp-python`（.dll） | **`llama-server.exe` を別に起こす** |
| 増える実行ファイル | なし | **1つ増える** |

だから `runtime.kind: "inproc"` を足した（`src/runtime/inproc.ts`）。
`node-llama-cpp` は中身が `.dll` と `.node` だけで、`.exe` は0個（実測）。

上の層は OpenAI 互換の口しか見ないので、**その口を自分の中に立てる**
（127.0.0.1 のみ。外へ出る口は増えない）。上の層は一行も変えていない。

### 言い方を間違えた

「ライブラリを足すと環境依存になる」と言ったが、逆。
**足りない環境に合わせて入れるのは、環境に対応したというだけ。**
`node.exe` を同梱しているのと同じ話で、破っているものは無い。

### Node にこだわる理由は無い

私が最初にそう決めただけで、要件ではない。ただし今回の壁は Node ではなく、
「二つ目の実行ファイルを起こす」という作りだった。言語を替える必要は無かった。

### 全機械むけの binary を入れない

`npm install node-llama-cpp` をそのまま叩くと 1.1GB になる。

- CUDA 版・mac 版・arm 版まで来る（**`--os` / `--cpu` は効かない。試した**）
  → `--omit=optional` で持ってこない。配る相手の分だけ名指しで入れる
  （Linux で組むので `--force` が要る）
- postinstall が llama.cpp のソースを取ってきて手元で組む（+292MB。
  Linux むけなので配る相手には要らない）→ `--ignore-scripts`

結果、配布物は 42MB（node 抜き・実測）。`.exe` は0個。
