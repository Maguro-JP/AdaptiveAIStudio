# 手元のモデルを使う

モデルが無くても、画面・点検・preview・色の道具は動きます。
モデルを置くと、そこに「考えさせる」が加わります。

外へは出しません。宛先は手元だけです。

## 動かし方は三つ。増える実行ファイルの数で選ぶ

| | 増える実行ファイル | 速さ | 向いている場所 |
|---|---|---|---|
| **この中で読む**（`inproc`） | **なし** | 中（CPU） | 何も入れられない機械 |
| Ollama | 別に立てる | 中〜速 | 手早く始めたいとき |
| llama.cpp（`llamacpp`） | 1つ増える | 速（GPU） | 速さが要るとき |

**何も入れられない機械では `inproc` だけが道になります。**
モデルを読むのは `.dll` と `.node`（アプリの中に入っているライブラリ）で、
新しい実行ファイルは増えません。

## この中で読む（`inproc`）

### 1. GGUF を1つ置く

置き場は、画面の `⚙ 設定 → モデル` に出ています。
ファイル名は問いません。複数置くと一覧に並びます。

```
AdaptiveAIStudio\
  data\
    models\
      qwen2.5-3b-instruct-q4_k_m.gguf
```

### 2. 画面で選ぶ

`⚙ 設定 → モデル` で「この中で読む」を選んで保存し、同じ場所に出る
**「立ち上げ直す」を押します。**（切り替えは立ち上げ直すまで効きません。
画面もそう言い、要るときだけそのボタンが出ます）

置き場が無ければ、既定の置き場はこちらが作ります。打ち込んだ置き場が
無いときは、作らずにそう言います（打ち間違いをフォルダにしないため）。
取ってこられない機械（会社の PC）では、ブラウザで開く先と置く先を出します。

設定ファイルに直接書くなら、こうです。

```json
{ "runtime": { "kind": "inproc", "modelsDir": "GGUF を置いた場所" } }
```

## どの GGUF を選ぶか

公式の配布元から、名前に `GGUF` が付いたものを1つ落とします。

- Qwen: https://huggingface.co/Qwen

版が上がると名前が変わるので、個別のファイル名は書きません。選び方だけ。

- **大きさ**: 要約・分類なら 3B、コードの下書きなら 7B
- **量子化**: 迷ったら `Q4_K_M`。品質と大きさの釣り合いが良い
- **目安**: 3B の Q4_K_M で約 2GB、7B で約 4.7GB

落とすのは網に出られる機械で行い、閉じた場所へはファイルを持ち込みます。

GGUF は同梱しません。数GBあり、数か月で新しいものが出ます。
アプリと一緒に固定すると、入れ替えのたびにアプリごと配り直すことになります。

## 置き場が全角のとき

利用者名が全角だと、置き場も全角になります。llama.cpp 系はそこからモデルを
開けないことがあるので、**モデルだけ** `%ProgramData%\AdaptiveAIStudio\models`
へ逃がします（自動。`src/core/home.ts` の `asciiModelsDir`）。

## 速さについて

`inproc` は CPU で動きます。GPU を使う `llamacpp` より遅くなります。
自宅の機械のように速さが要るところでは `llamacpp`、何も入れられない
機械では `inproc`、と使い分けてください。設定を変えるだけで切り替わります。

## 確かめる

画面の `⚙ 設定 → 点検 → この環境を見てもらう`（端末なら `npm run doctor`）。
モデルが見つかっていれば、そう言います。見つからなければ、どこを見に行って
いるかを言います。
