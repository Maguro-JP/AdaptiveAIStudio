# ADR 0002: フォールバックは必ず可視化する

- 状態: 採用
- 日付: 2026-08-30

## 背景

自動フォールバックの最悪の失敗は「暗黙に起きて気づかない」こと (R6)。
ローカルモデルへ落ちたことに気づかないまま設計判断を任せると、
品質劣化の原因を後から追跡できない。

## 決定

1. `ChatOrchestrator` は切替時に必ず `{ type: 'fallback', from, to, reason }` を発行する。
2. 完了イベント `done` に `modelId` と `fallbackFrom` を含め、
   メッセージ単位で使用モデルを永続化する (`messages.model_id` / `fallback_from`)。
3. UI はメッセージにモデルバッジを表示し、切替時はトーストで通知する。

## 帰結

- 履歴からいつ・なぜ・どのモデルに落ちたかを再構成できる。
- 「安く済ませるための黙った降格」は構造的に作れない。
