このフォルダに node.exe を置いてください。

  https://nodejs.org/dist/v24.18.0/win-x64/node.exe

インストーラではなく、実行ファイルが 1 本落ちてきます（約 80MB）。
ここへ置くだけで、start.cmd がこちらを先に使います。
この PC には何も入りません。フォルダごと消せば跡形もなくなります。

Node を入れられる PC なら、このフォルダは空のままで構いません。
https://nodejs.org/ の LTS 版が使われます。

＊ 落としてくるのも面倒なときは、Node ごと入った版があります。
   https://github.com/Maguro-JP/AdaptiveAIStudio/releases
