# 二度としないこと

利用者が実際に嫌がったこと。**話題が違っても効く。**
新しく嫌がられたら、その場でここへ足す（言われた言葉のまま）。

- **日本語で返す。**圧縮された直後も戻さない。
  「日本語でって言ってるよね 圧縮する度にそれ止めてもらえるか?」
- **「配布物」と言わない。**訳語を作らない。bundle / setup.exe / portable のまま呼ぶ。
  「配布物って気持ち悪いから言わないで」
- **「動く」を「起動する」の意味で使わない。**
  「車のエンジンかけたことを動いたとは言わねぇ」
- **動かないものを渡して、確認させない。**ログを取らせない。原因はこちらで潰す。
  「動かないものを作ったお前が原因だろうが」
- **確かめていないことを、確かめた顔で言わない。**「たぶん」で断定しない。
- **CLAUDE.md にゴミを足さない。**守らせたいことは、文章ではなく実行の手前で止める。
- **USB を社用PCに挿す提案をしない。**社用PCの前提は利用者が決めたもの。覆さない。
- **CI（GitHub Actions）を断りなく回さない。**手で回すのも聞いてから。
- **UI は普通の作法に従う。**設定の奥に主要な操作を隠さない。参考にできるものがあるなら見る。
- **止まったら、自分で再開の仕掛けを作る。**利用者に叩き起こさせない。
  「結局止まってんじゃん」
- **`pkill -f` / `pgrep -f` に、自分の命令行にも当たる文字列を渡さない。**（二度自分を殺した）
- **相手が何の話をしているかを取り違えない。**
  記憶の話をしているときに、製品のコードだけ書いて自分のことに触れない、をやった。
  設計の話は、こちらの振る舞いの話でもある。
